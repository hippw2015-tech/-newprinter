# سجل الورديات — مشروع APK

## البناء
1. أنشئ مستودعًا **خاصًا (Private)** على GitHub وارفع كل محتويات المجلد (مع `.github` و`signing`).
2. من تبويب Actions شغّل **Build APK**، وبعد اكتماله بعلامة خضراء نزّل `nursing-apk` وثبّته.
3. عند أول فتح تُنشئ كلمة مرور تُشفَّر بها بياناتك. نسيانها يعني ضياع البيانات، فاحتفظ بنسخة احتياطية.

## النسخة الاحتياطية
الإعدادات ← "حفظ / مشاركة" يُنشئ ملفًا مشفّرًا (`.nrs`) ترسله لنفسك. بعد إعادة التثبيت اختر "استرجاع من نسخة احتياطية" وأدخل كلمة المرور نفسها.

## مفتاح التوقيع
`signing/release.p12` يوقّع التطبيق دائمًا بنفس المفتاح فتُحدَّث النسخ فوق بعضها. لا تحذفه واحتفظ بنسخة منه، وأبقِ المستودع خاصًا.

## مؤجَّل لإصدار لاحق
التفعيل بالرقم التسلسلي: أداته محفوظة في `later/license-tool.html` ولا تؤثر على التطبيق حاليًا.
